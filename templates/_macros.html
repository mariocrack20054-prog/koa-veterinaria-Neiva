{# _macros.html - Piezas reutilizables de las plantillas ----------------------------------------------------------------------- Una macro de Jinja2 es como una función de Python pero para HTML. Las escribí aquí para no repetir el mismo código en las 5 tablas. Se importan en cada plantilla con: {% import "_macros.html" as m %} y se usan así: {{ m.banner(...) }} #} {# banner: encabezado con foto de fondo que sale arriba de cada sección. - titulo, subtitulo: textos que se muestran - foto: nombre del archivo que está en static/img/ - url_nuevo, texto_nuevo: (opcionales) botón para crear un registro #} {% macro banner(titulo, subtitulo, foto, url_nuevo=None, texto_nuevo=None) %}

{{ titulo }}

{{ subtitulo }}

{% if url_nuevo %} {{ texto_nuevo }} {% endif %}
{% endmacro %} {# acciones: celda con los botones Editar y Eliminar de cada fila. El botón Eliminar no borra directamente: abre el modal de confirmación (está en base.html) y le pasa la URL y el nombre por atributos data-. #} {% macro acciones(url_editar, url_eliminar, nombre) %} {% endmacro %} {# botones_form: botones Guardar y Cancelar al final de los formularios #} {% macro botones_form(url_cancelar) %}
Cancelar
{% endmacro %}
